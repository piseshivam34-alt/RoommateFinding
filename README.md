🏠 Roommate Sync

Smart compatibility matching for stress-free shared living 🚀 Overview

Roommate Sync is a web-based platform designed to help people find compatible roommates before finding a place. Instead of choosing accommodation first and adjusting later, we reverse the flow: match people first → find a place together.

This approach reduces conflicts and creates healthier shared-living experiences.

👉 Problem Statement

Most roommate platforms focus on:

Rent

Location

Availability

They ignore lifestyle compatibility, which leads to:

Daily conflicts

Poor communication

Early roommate breakdowns

💡 Our Solution

Roommate Sync evaluates compatibility using:

Sleep habits

Cleanliness preferences

Food choices

Budget comfort

Each user receives a clear compatibility score with visual insights.
